## 4. JS ↔ DOM coupling (regression risks)

- Tab click handler 10758–10788: `.file-tab` opens #file-menu; other tabs show content; hides all `.ribbon-content` first. **Class-coupled (`.file-tab`, `.ribbon-content`).**

- `setSidebarOpen()` 10561: `#sidebar-dock.classList.toggle('open')` + delayed `canvas.resize()`.
- `updateTitle()` 18315: `.window-title` textContent.
- Embedded re-parent script 2265–2278: moves `.qat`/`.window-title` into `.ribbon-tabs`, removes `.title-bar`. **Structure-coupled.**
- updateContextualTools 10280: `#edit-tools-tab`, `#tab-edit-tools`, `.contextual-*-tools` groups.
- `[data-command]` global delegation (10596) — **keep every data-command intact.**
- Canvas resize reads canvas-container geometry; sidebar transitions use 160 ms timeout — keep transition timing sane or resize on transitionend.
- File menu opened by `.file-tab` click (10758); dismissed by outside pointerdown (10623) + Escape (10629), referencing `.tab.file-tab`.
